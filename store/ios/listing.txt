ENGLISH
================================================================
Name: Tuneit
Subtitle (30): Guitar & bass tuner
Promotional text (170):
Offline chromatic tuner for guitar and bass. 80+ tunings, reference tones and a metronome — no ads, no account, no network.

Description:
Tuneit is a chromatic tuner for guitar and bass. It stays on your phone: no account, no ads, no analytics, no internet.

Open the app, play a string, and watch cents and note name update as you tune. Auto mode picks the nearest string. Manual mode locks one string. Chromatic mode shows any pitch.

Includes a tuning library for 6-, 7-, 8- and 12-string guitar, baritone, and 4-, 5- and 6-string bass: standard, drop, lowered, open and alternate tunings. Save your own custom tunings. Long-press a string to hear a reference tone.

A built-in metronome with tap tempo, time signatures, subdivisions and an optional haptic pulse.

Calibration from 435–445 Hz so every preset follows your A4. Works fully offline. Microphone audio is processed on-device and never uploaded.

APP REVIEW NOTES
================================================================
Tuneit is an offline chromatic tuner. No login.

On first launch iOS asks for microphone access so the tuner can hear a string. Grant it to see pitch. If you deny, reference tones and the metronome still work.

There is no account, no IAP in this build, no ads, and the release build does not use the network.

BUILD AND UPLOAD (Mac with Xcode + paid Apple Developer account)
================================================================
1. Open ios/Runner.xcworkspace in Xcode (not the .xcodeproj).
2. Signing & Capabilities → Team NY54WRBFV6 (already set, same as Sprint App).
3. Enable GitHub Pages (docs folder) or host docs/privacy.html and paste the URL in App Store Connect.
4. From the project root:

   flutter pub get
   cd ios && pod install && cd ..
   flutter build ipa --release --export-options-plist=ios/ExportOptions.plist

5. Upload the IPA with Transporter, or:
   xcrun altool --upload-app --type ios --file build/ios/ipa/tuneit.ipa --apiKey KEY --apiIssuer ISSUER

   Or in Xcode: Product → Archive → Distribute App → App Store Connect.

6. In App Store Connect: create the app, paste listing text, attach screenshots, attach the build, submit for review.
